# Bài tập

Quy ước đặt tên file:

```
<phase>-<số>-<tên-ngắn>.sql
ví dụ: A-03-select-coil-theo-grade.sql
```

Mỗi file bắt đầu bằng header:

```sql
/* =============================================
   Bài:      A-03
   Đề:       (chép lại đề bài ở đây)
   Ngày:     2026-__-__
   Lần thử:  1
   ============================================= */
```

QUY TẮC: gõ tay, không copy-paste.
